There are several ways to reverse a string in Python:

1. Slicing (most Pythonic)

s = "hello" reversed_s = s[::-1] print(reversed_s) # "olleh"

2. Using reversed() + join()

reversed_s = "".join(reversed(s))

3. Loop

for char in s: result = char + result

The slicing method [::-1] is generally preferred for brevity.
